# ECOROM

Единая система завода окон ECOROM: заказы, цех, склад, монтаж, сервис, деньги.

- Сайт: https://eyuldashev3333-prog.github.io/EcoRom/
- `app/` — сайт (React + TypeScript + Vite, PWA/Telegram Mini App), интерфейс на узбекском.
- `supabase/migrations/` — схема базы (PostgreSQL, права по ролям через RLS).
- Секретов в репозитории нет: ключи и токены хранятся вне репозитория.
