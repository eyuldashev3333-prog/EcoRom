# e2e-тесты ECOROM (боевая база Supabase, временные пользователи)
Запуск строго по порядку, из папки scripts/e2e: `node b1.mjs`, `b2.mjs`, `b2b.mjs`, `b3.mjs`, `b4.mjs`, `b5.mjs`, `b6.mjs` (каждый печатает PASS/FAIL).
Нужны `.env.local` (токены) и Node 24. На время теста у Elyor отключается Telegram (чтобы не слать сообщения владельцу), у тестовых людей фейковые Telegram-ID.
После тестов ОБЯЗАТЕЛЬНО: `node cleanup-e2e.mjs` (удаляет всё тестовое и возвращает Telegram Elyor).
- b1 — доступы (цех/монтажник видят только своё, audit_log, последний Rahbar, пароли)
- b2/b2b — оплаты (переплата, дубль, даты), переходы статусов, ограничения значений, возврат, сервис, бой
- b3 — правка заказа в работе/после цеха
- b4 — уведомления (недоставка, повтор, нет получателей, эскалация, тихие часы, дайджесты)
- b5 — проверки калькуляции (нулевая цена, размеры), b5ui.mjs — браузер: цены заказа не меняются задним числом (нужен `vite preview` на 4173)
- b6 — фото монтажа, зарплата, склад, таблицы
- s1…s10 — исходные сценарии первого теста (для сравнения «до»), cmp_reg.mjs — сверка REGISTRATSIYA.xlsx с базой, ui1.mjs — обход экранов по ролям.
Тесты используют общий файл ctx*.json в рабочей папке — запускайте из одной папки.
